# PS退火时间逆向预测 — 代码审查与优化方案

## 当前状态概要

项目使用 Nadaraya-Watson RBF 核回归器，从退火参数 (T1, t1, T2, t2) 预测焓恢复目标 (delta_h, peak_area, H*, S*)，然后通过固定 (T1, T2) 的网格搜索反推 (t1, t2)。

**核心结果**：仅 **3个两步条件** 可用于条件时间逆向评估（50→100、50→80、65→100）。t2 预测的 log10 MAE 为 **0.97**（因子误差约 9 倍），50→80 条件的 t2 误差高达 **180 倍**。这不是代码 bug，而是根本性的可辨识性问题。

---

## 根因分析（5个问题）

### 1. t1 实际上没有被真正预测 — 只是边界效应

三个评估条件的实际 t1 均为 10s，模型预测 t1 也全部是 10s。这是因为 10s 是候选网格 `[10, 30, 60, 100, 300, 600, 900, 1200, 1800]` 的下边界。模型在训练中从未见过这些 T1 值下 t1 ≠ 10s 的样本，所以默认预测边界值。**没有实验上的 t1 变化，就无法验证 t1 的预测能力。**

### 2. 50→80°C 条件毒化了留一法评估

该条件的 Kissinger R² = 0.94（"low" 置信度）。其目标 H* = 587 kJ/mol 和 S* = 1341 J/mol·K 远超其他训练点的范围（H* ~460-540，S* ~1000-1080）。当该条件被留出时，模型在其余 5 个点上训练后无法外推到 H* = 587，导致 t2 预测为 10s（实际为 1800s），误差 180 倍。

### 3. 不同 (t1, t2) 组合产生几乎相同的目标向量

这是根本性的物理问题。在 T1 = 50°C（远低于 PS 的 Tg ≈ 95-100°C）时，弛豫极其缓慢。t1 = 10s 还是 t1 = 600s 在 50°C 下对最终焓状态几乎没有影响——材料几乎不弛豫。目标值 (delta_h, peak_area, H*, S*) 由 T2 阶段的退火主导。因此损失函数沿 t1 方向是平坦的，模型无法区分。

### 4. 特征空间未编码 Kovacs 记忆效应的物理

`src/ps/train_ps_model.py:88` 中的 `featurize()` 函数仅使用 7 个原始代数特征：

```python
FEATURES = [
    "is_two_step", "T1_C", "T2_C_filled", "delta_T_C",
    "log_t1_s", "log_t2_s", "log_total_time_s"
]
```

对于固定的 (T1, T2)，仅有 `log_t1_s` 和 `log_t2_s` 变化。两个不同的 (t1, t2) 对可以具有相同的 `log_total_time_s`，使模型无法区分。而 `src/ps/physics_features.py` 中的物理信息特征（TNM 弛豫剂量、ARRT 状态进展）**已实现但未接入条件时间逆向流程**。

### 5. 条件逆向模型仅有 3-6 个训练点

严格 paper-style 模型（`src/ps/conditional_time_inverse.py:93` 中的 `fit_strict_paper_model`）在所有具有有效 H*/S* 的行上训练——仅 6 个条件（3 个单步 + 3 个两步）。使用留一法交叉验证时，模型在 5 个点上训练、1 个点上测试。一个只有 5 个训练点的核回归器无法可靠地学习 4 目标的映射。

## 代码优化方案

### 优化 1：将物理特征接入条件时间逆向（优先级：最高）

**文件**：`src/ps/conditional_time_inverse.py`

**现状**：`feature_matrix()` 调用 `featurize()`，仅有 7 个原始特征。

**改动**：替换为 `src/ps/physics_features.py` 中的 `physics_feature_dict()`，获得约 257 个 TNM/ARRT 特征。关键收益：对于固定 (T1, T2)，不同 (t1, t2) 对现在映射到**不同的特征向量**，因为 TNM 剂量特征编码了弛豫进展的非线性耦合。

```python
from src.ps.physics_features import physics_feature_dict, PHYSICS_FEATURES

def feature_matrix_physics(rows):
    feats = [physics_feature_dict(row) for row in rows]
    return np.array([[feat[name] for name in PHYSICS_FEATURES] for feat in feats], dtype=float)
```

由于物理特征尺度不同，bandwidth 需调大至 2.0-5.0 范围。

**预期效果**：t2 log10 MAE 从 0.97 → 0.4-0.6。

### 优化 2：排除或降权低置信度的 50→80 条件（优先级：最高）

**文件**：`src/ps/conditional_time_inverse.py`、`src/ps/evaluate_conditional_time_inverse.py`

**方案 A**（推荐）：在 `fit_strict_paper_model()` 中排除 `kissinger_confidence == "low"` 的行。

**方案 B**：应用与 Kissinger R² 残差成反比的样本权重：
```python
weight = max(0.1, 1.0 / (1.0 - kissinger_r2))
```

**预期效果**：消除灾难性的 180 倍离群误差。

### 优化 3：引入物理正则化损失函数（优先级：高）

**文件**：`src/ps/conditional_time_inverse.py`

在 `conditional_loss()` 中添加物理约束惩罚项：

```python
def conditional_loss_with_physics(target_loss_value, total_time_s, 
                                   uncertainty_values, T1_C, t1_s, T2_C, t2_s):
    base_loss, components = conditional_loss(target_loss_value, 
                                              total_time_s, uncertainty_values)
    
    # 物理惩罚 1：当 T1 << Tg 时，长 t1 不应显著改善拟合
    # 因为在低温下弛豫极其缓慢
    T1_K = T1_C + 273.15
    if T1_K < 353.15:  # 80°C 以下
        t1_penalty = 0.01 * (t1_s / 1800.0)
    else:
        t1_penalty = 0.0
    
    # 物理惩罚 2：对于升温跳跃，当 t1 剂量饱和后边际效应递减
    if T2_C > T1_C:
        # 计算 TNM 剂量判断是否已饱和
        from src.ps.physics_features import physics_feature_dict
        phys = physics_feature_dict({
            "mode": "two_step", "T1_C": T1_C, "t1_s": t1_s,
            "T2_C": T2_C, "t2_s": t2_s
        })
        if phys.get("tnm_state_step1_e430_b050", 0) > 0.95:
            saturation_penalty = 0.02
        else:
            saturation_penalty = 0.0
    else:
        saturation_penalty = 0.0
    
    total = base_loss + t1_penalty + saturation_penalty
    components["t1_physics_penalty"] = t1_penalty
    components["saturation_penalty"] = saturation_penalty
    return total, components
```

### 优化 5：引入高斯过程回归替代 Nadaraya-Watson（优先级：中）

**新文件或修改**：`src/ps/conditional_time_inverse.py`

当前 Nadaraya-Watson 估计器在数据稀疏区域给出过于自信的预测。替换为 GP 回归以获得更好的不确定性校准：

```python
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern, WhiteKernel

kernel = Matern(length_scale=1.0, nu=2.5) + WhiteKernel(noise_level=0.1)
gp = GaussianProcessRegressor(kernel=kernel, normalize_y=True, alpha=1e-6)
gp.fit(x_train, y_train)
pred, std = gp.predict(x_test, return_std=True)
```

GP 的后验方差会在远离训练数据的区域（如 50→80 条件）正确地膨胀，而不是给出误导性的紧致不确定性估计。

### 优化 6：训练直接逆向模型（优先级：中）

**新文件**：`src/ps/direct_inverse_model.py`

与其训练正向模型 (T1,t1,T2,t2 → targets) 再做网格搜索，不如直接训练逆向模型：

```python
# 直接逆向模型：输入 (T1, T2, delta_h, peak_area, H*, S*) → 输出 (log_t1, log_t2)
x_inverse = np.column_stack([
    T1_C, T2_C, 
    delta_h_total_J_g, peak_area_J_g, 
    activation_enthalpy_H_star_kj_mol, 
    activation_entropy_S_star_j_mol_K
])
y_inverse = np.column_stack([np.log10(t1_s), np.log10(t2_s)])
model_inverse = KernelRegressor.fit(x_inverse, y_inverse, bandwidth=1.5)
```

这更数据高效，因为每个训练点直接教会模型 t1、t2 的映射关系。

### 优化 7：增加特征筛选步骤（优先级：低）

**文件**：`src/ps/conditional_time_inverse.py`

257 个物理特征对于 5-6 个训练点来说过多。使用互信息或相关性筛选，保留与 t1、t2 对数最相关的 top-15 特征：

```python
from sklearn.feature_selection import mutual_info_regression

# 筛选与 log_t1、log_t2 最相关的特征
mi_t1 = mutual_info_regression(x_physics, y_log_t1)
mi_t2 = mutual_info_regression(x_physics, y_log_t2)
mi_combined = mi_t1 + mi_t2
top_features_idx = np.argsort(mi_combined)[-15:]
```

## 实验设计原则

### 原则 1：每个 (T1, T2) 组合至少需要 3 个不同的 t1 值

对于固定 (T1, T2) 的条件逆向，模型需要看到 t1 的变化才能学会区分。如果所有训练数据的 t1 都相同，模型只能猜测边界值。

### 原则 2：多升温速率实验是所有两步条件的必需品，而非可选项

没有 4 个升温速率的 Kissinger 分析，就无法计算严格 H*/S*。没有严格 H*/S*，该条件就无法用于 paper-style 目标集的训练或评估。**每个新的两步条件都应配套 4 个升温速率。**

### 原则 3：优先填补空白而非增加密度

当前数据集的主要问题是**覆盖稀疏**（T1 只有 3 个值，T2 只有 2 个值，t1 只有 1 个值），而非噪声过大。在已有数据点附近增加更多重复实验的收益很低，优先扩展 T1、T2 和 t1 的范围。

### 原则 4：利用物理知识设计实验

TNM 模型预测，当 T1 远低于 Tg 时，t1 的影响呈指数级衰减。因此：
- 在 T1 = 50°C 时，t1 ∈ {10, 300, 1200}s 的差异可能很小
- 在 T1 = 80°C（接近 Tg）时，同样 t1 范围的差异会大得多
- 最有信息量的实验是 T1 接近 Tg 的区间（70-90°C），因为这里 t1 和 t2 的效应相当

## 根本性限制（需正视）

即使以上所有优化都实施，**当 T1 远低于 Tg 时，t1 可能本质上无法从 DSC 数据中唯一确定**。这是物理上的限制，而非建模问题——如果材料在 T1 下几乎不弛豫，那么 DSC 信号中就没有关于 t1 的信息。

在这种情况下，模型能做的最好事情是：
1. 报告 t1 的宽后验区间（诚实地表达不确定性）
2. 给出 t2 的合理估计（因为 T2 阶段的信号占主导）
3. 对于 t1，输出物理上合理的上界（"t1 可能不超过 X 秒，否则 T1 阶段的弛豫会在信号中留下痕迹"）

这本身就是一个有科学价值的结论——它量化了"记忆"在什么条件下可被读出。
