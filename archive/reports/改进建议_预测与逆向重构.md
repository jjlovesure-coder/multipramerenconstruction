项目分两条互补路线：

```
热历史 (T₁, t₁, T₂, t₂)
    │
    ├──→ 物理特征工程 (ARRT + TNM + 经验关系)
    │         │
    │         ▼
```

## 改进建议 (按优先级排序)

### 🔴 高优先级 — 高影响 + 易实现

#### 1. 各向异性核 / ARD (Automatic Relevance Determination)

**当前问题:**

RBF 核回归对所有特征使用**同一个 bandwidth σ** (代码中写死为 1.25 或 1.2)。但 T₁ (量级 350K)、log t₁ (量级 0-3)、TNM dose (量级 0-1) 的尺度和影响力完全不同。等向性假设严重限制了模型的表达能力，也无法告诉我们哪些物理特征真正重要。

**改进方案:**

每个特征学习独立的 bandwidth σₖ，核函数变为各向异性高斯核 (ARD kernel):

```
w_ij = exp(-0.5 * Σₖ (x_ik - x_jk)² / σₖ²)
```

实现只需修改 `src/models/kernel_regression.py` 第 35 行的 `dist2` 计算:

```python
# 当前 (等向性)
dist2 = np.sum(diff * diff, axis=2)
weights = np.exp(-0.5 * dist2 / (self.bandwidth ** 2)) + self.ridge

# 改进后 (ARD, 各向异性)
inv_bandwidth_sq = 1.0 / (self.bandwidth ** 2)  # self.bandwidth 变为向量
dist2 = np.sum(diff * diff * inv_bandwidth_sq[None, None, :], axis=2)
weights = np.exp(-0.5 * dist2) + self.ridge
```

Bandwidth 向量可通过留一法对数似然最大化来优化，或简化为对每个特征做单变量核密度估计的 Silverman 规则作为初值。

**预期效果:**

- 自动发现高权重特征 (如 log_t1, inv_T1_K 等 Arrhenius 坐标特征)
- 压制噪声特征，提高泛化能力
- 预期核心目标归一化误差降低 5-10%

**实现难度:** 低。核心改动 <10 行。

#### 2. 学习 PS 专属的 TNM 弛豫参数

**当前问题:**

TNM 参数 **全部照搬金属玻璃文献值**:

| 参数 | 当前值 | 来源 | 问题 |
|------|--------|------|------|
| H* | 164 kJ/mol | 金属玻璃文献 | PS 是聚合物, 弛豫活化能不同 |
| A | 6×10⁻²² s | 金属玻璃文献 | 指前因子强烈依赖于材料 |
| β | 0.43 | 金属玻璃文献 | 拉伸指数反映弛豫时间分布宽度 |
| x | 0.6 | 金属玻璃文献 | 非线性参数, 未实际使用但存于代码 |
| T_REF_K | 373.15 | 随意设定 | 无物理依据 |
| TAU_REF_S | 100.0 | 随意设定 | 同上 |

`physics_features.py` 中甚至用了一个能量网格 `(120, 160, 200, 430, 460, 540 kJ/mol)` 来"覆盖"可能的 H* 值, 其中 430-540 kJ/mol 仅基于 3 个 hs-01 锚点——这是一种"撒网"策略, 而非真正的参数估计。

**改进方案:**

将 TNM 参数作为可优化的超参数, 在 PS 训练集上通过 grouped CV 搜索最优值:

```python
# 参数搜索空间 (PS合理的范围)
param_space = {
    "H_kj_mol": (120, 200),      # 聚合物弛豫活化能通常低于金属玻璃
    "log10_A_s": (-24, -18),     # 指前因子对数空间
    "beta": (0.30, 0.70),        # 拉伸指数
    "T_ref_K": (363.15, 383.15), # PS的Tg附近 (~373K)
    "tau_ref_s": (10, 1000),     # 参考弛豫时间
}
```

优化目标: 最小化 grouped CV 中核心目标 (ΔH_total, peak_area, recovery_index, path_dependence_index) 的归一化 MAE。

具体做法:
1. 对每组候选参数, 重新计算所有样本的 TNM dose/state 特征
2. 用 5-fold grouped CV 评估 RBF 核回归的预测误差
3. 贝叶斯优化 (如 scipy `differential_evolution` 或 `gp_minimize`) 在参数空间搜索

**预期效果:**

- 核心目标归一化误差预计降低 10-15%
- 减少特征维度 (从 18+ 组 dose 特征 → 1-2 组真正有效的)
- 物理特征获得 PS 专属的诠释

**实现难度:** 中。需要新增一个超参数搜索脚本, 但核心特征计算逻辑不变。

#### 3. 加入交互特征 (Interaction Features)

**当前问题:**

所有特征都是独立编码的。但玻璃态弛豫的本质是**路径依赖性**——T₁ 和 t₁ 的效应通过 TNM 序列状态更新相互耦合, 不是可加的。当前特征集缺少显式的"对比度"特征来编码两步之间的差异。

**改进方案:**

在原始特征之上新增交互项 (建议添加到 `src/ps/train_ps_model.py` 的 `featurize()` 和 `src/models/dataset.py` 的特征列表中):

```python
# 新增交互特征
"T1_logt1": T1 * np.log10(t1),             # 第一步的累积弛豫效应 (Arrhenius × 时间)
"T2_logt2": T2 * np.log10(t2),             # 第二步的累积弛豫效应
"delta_T_log_ratio": delta_T * np.log10(t2 / max(t1, 1e-9)),  # 两步对比度
"inv_T1_inv_T2_product": (1/T1) * (1/T2),  # Arrhenius坐标耦合
"inv_T1_inv_T2_diff": 1/T1 - 1/T2,         # Arrhenius温差 (正比于弛豫时间比的对数)
"log_t_ratio": np.log10(t2 / max(t1, 1e-9)),  # 时间比
"total_dose_product": dose1 * dose2,       # 两步剂量耦合
"dose_asymmetry": abs(dose1 - dose2),       # 两步剂量不对称性
```

这些特征直接编码了已知物理:
- `delta_T_log_ratio`: 两步之间温度差 × 时间对比, 这是 Kovacs 记忆效应出现的必要条件
- `inv_T1_inv_T2_diff`: Arrhenius 坐标下的温差, 与弛豫时间的指数差异成正比
- `dose_asymmetry`: 两步弛豫完成度的差异, 不对称性越大越容易出现双峰

**预期效果:**

- 改善 path_dependence_index 的预测 (当前 MAE 较高)
- 增强对两段式退火行为的区分能力
- 几乎零成本

**实现难度:** 低。在每个 `featurize()` 函数中加 ~8 行。

#### 4. 改进 S* 的插值方式

**当前问题:**

`src/models/dataset.py:_nearest_by_log_time()` 在 S7 图中按最近温度 + 最近 log t 匹配 S*。但 S7 仅覆盖 4 个温度 (348, 363, 373, 383K), 逆向设计时 T₁ 可能取 353, 358, 368K 等中间值。直接用最近邻引入系统性偏差——例如 T₁=358K 时的 S* 会被当作用 T₁=363K 的值, 偏差可达 5-10 J/mol·K。

**改进方案:**

对 S*(T, log t) 曲面做薄板样条 (Thin-plate Spline) 或高斯过程插值:

```python
from scipy.interpolate import RBFInterpolator

# 从 S7 散点构建插值器
s7_points = ...  # (T, log_t) → S*
s7_interpolator = RBFInterpolator(
    s7_points[:, :2],  # (T, log_t)
    s7_points[:, 2],   # S*
    kernel='thin_plate_spline'
)

# 任意 (T, log t) 下平滑估计 S*
s_star = s7_interpolator([[T, np.log10(t)]])
```

同样的方法也应用于 Fig.3 H*/Tp 的经验关系, 当前也是按最近 log t 匹配。

**预期效果:**

- 消除 S* 插值带来的系统性偏差 (~2-5 J/mol·K)
- 改善 models/ 线的 S*₂ 和 ΔS* 预测

**实现难度:** 低。

#### 5. 交叉验证 Bandwidth + 重复分组划分

**当前问题:**

- `models/` 线: bandwidth = 1.25 手工指定, 无 CV 搜索
- `ps/` 线: bandwidth = 1.2 手工指定
- `evaluate_split.py`: seed=42 单次划分
- `train_ps_model.py`: seed=7 单次划分
- **当前报告的 MAE 本质上是点估计, 不知道方差有多大**

`train_physics_informed_ps_model.py` 已经有 grouped CV 选特征子集 + bandwidth 的框架, 但 models/ 线和基础 PS 线没有。

**改进方案:**

```python
BANDWIDTH_GRID = [0.5, 0.8, 1.0, 1.2, 1.5, 2.0, 3.0]
N_REPEATS = 10  # 不同种子重复分组划分

results = []
for seed in range(N_REPEATS):
    train_idx, test_idx = grouped_split(rows, seed=seed)
    for bw in BANDWIDTH_GRID:
        model = KernelRegressor.fit(x[train_idx], y[train_idx], bandwidth=bw)
        pred, _ = model.predict(x[test_idx])
        results.append({"seed": seed, "bw": bw, "mae": ...})

# 报告均值 ± 标准差, 而非单次点估计
```

**预期效果:**

- 发现真正最优的 bandwidth (当前 1.25 可能偏高, 导致过平滑)
- 获得误差估计的置信区间, 了解模型稳定性
- 对于论文投稿来说, 这是基本的统计严谨性

**实现难度:** 低。主要是改训练脚本的循环逻辑。

#### 6. 多输出相关性建模

**当前问题:**

所有 8 个 PS 目标 (或 5 个 models/ 目标) 是独立预测的——共享 kernel weights, 但不共享目标间的协方差结构。`compare_paper_style_targets.py` 明确确认了目标间存在高度冗余 (ΔH_total ↔ peak_area ↔ peak_height ↔ recovery_index 强相关)。

**改进方案 A — 链式预测 (最简单):**

选择最容易预测的目标 (ΔH_total, 当前 R² 最高), 先用核回归预测它, 然后将其预测值作为额外特征去预测其他目标:

```python
# Step 1: 预测 ΔH_total (最容易)
pred_dh, _ = model_dh.predict(x)

# Step 2: 用 [原始特征 + pred_dh] 预测其他目标
x_augmented = np.column_stack([x, pred_dh])
pred_others, _ = model_others.predict(x_augmented)
```

**改进方案 B — 多输出核回归:**

使用矩阵值核函数, 同时预测所有目标并利用它们之间的协方差。简化实现: 用共区域化线性模型 (LMC)。

**预期效果:**

- 改善弱信号目标 (如 path_dependence_index) 的预测, 因为它们可以"借用"强信号目标 (如 ΔH_total) 的信息
- 不增加任何新特征

**实现难度:** A 方案低, B 方案中。

#### 7. 连续优化替代网格搜索做逆向

**当前问题:**

逆向设计使用的是纯网格枚举:

| 参数 | models/ 线 | ps/ 线 |
|------|-----------|--------|
| T | 6-3 个温度点 | 11 × 11 个温度 |
| t | 13 × 13 个时间点 | 9 × 9 个时间点 |
| 总候选 | ~2000 | ~10,000 |

网格是离散的, 最优解可能落在网格之间。且 RBF 核回归的预测函数对输入是完全可微的 (高斯核有解析梯度), 所以基于梯度的连续优化完全可行。

**改进方案:**

使用 L-BFGS-B 在连续 (T₁, T₂, log t₁, log t₂) 空间上直接优化加权损失:

```python
from scipy.optimize import minimize

def loss(params):
    T1, T2, log_t1, log_t2 = params
    features = feature_row(T1, 10**log_t1, T2, 10**log_t2)
    pred = model.predict(np.array([features]))[0]
    return weighted_multi_objective_loss(pred, target)

result = minimize(
    loss,
    x0=[T1_init, T2_init, np.log10(t1_init), np.log10(t2_init)],
    bounds=[(340, 390), (370, 390), (-1, 3), (-1, 3)],
    constraints={'type': 'ineq', 'fun': lambda x: x[1] - x[0]},  # T2 ≥ T1
    method='L-BFGS-B'
)
```

同时保留网格搜索作为初值生成器 (多点启动避免局部最优)。

**预期效果:**

- 找到网格间隙中更优的解
- 对于精确匹配特定目标值 (如 ΔH = 0.55 ± 0.01) 的场景, 连续解比离散解更实用

**实现难度:** 中。需要实现目标函数对输入参数的梯度 (解析梯度) 或接受数值梯度的开销。

#### 8. 不确定性校准与 EIG 质量检验

**当前问题:**

EIG 代理量 `0.5 * log(1 + σ²_pred / σ²_noise)` 中的 `σ²_pred` 是**加权训练目标方差**, 不是真正的预测不确定性。具体来说, `KernelRegressor.predict()` 返回的 uncertainty 是:

```python
variance = Σ_j w_ij * (y_j_train - ŷ_i)²
```

这度量的是**训练目标在预测点附近的分散程度**, 而非模型对该预测的置信度。在训练数据稀疏的区域, 这个值可能因为邻域内样本恰好一致而偏小 (虚假高置信度), 也可能因为邻域内样本差异大而偏大。

**改进方案:**

1. **Calibration plot**: 将预测不确定性 vs 实际绝对误差做散点图。如果 Pearson r < 0.3, 说明 EIG 代理基本无效
2. **保序回归校准**: 用 isotonic regression 将原始 uncertainty 映射到校准后的 uncertainty
3. **共形预测**: 用 conformal prediction 获得有覆盖率保证的预测区间

```python
# Calibration check (快速诊断)
actual_errors = np.abs(y_pred - y_true)
predicted_uncertainties = uncertainty_from_model
r, p = scipy.stats.pearsonr(predicted_uncertainties, actual_errors)
print(f"Uncertainty calibration Pearson r = {r:.3f}")
# 如果 r < 0.3, EIG 定向基本随机
```

**预期效果:**

- 了解 EIG 是否真的在指向"值得做"的实验
- 提高下一轮实验设计的效率
- 对论文的方法学部分, 这是重要的自我批判

**实现难度:** 低。calibration check <20 行代码。

#### 9. 特征选择替代特征堆叠

**当前问题:**

`physics_features.py` 生成 100+ 维物理特征, 然后 `train_physics_informed_ps_model.py` 用 grouped CV 从中选最优子集。这本质上是将模型选择负担完全交给了 CV——但样本量极少 (~50-60 训练样本), 100+ 维特征做 CV 选择可能过拟合。

**改进方案:**

在 CV 之前加一道**基于物理的特征筛选**:

```python
# 1. 相关性过滤: 移除与所有目标相关性 < 0.1 的特征
# 2. 冗余性过滤: 对相关系数 > 0.95 的特征对, 保留与目标相关性更高的
# 3. 稳定性过滤: 移除在不同 CV split 中符号不一致的特征
```

将特征池从 100+ 缩减到 20-30 个最有希望的, 再在 CV 中精细选择。

**预期效果:**

- 减少 CV 选择的方差 (更少的候选意味着更稳定的选择)
- 避免纯统计驱动选择没有物理意义的特征组合

**实现难度:** 低。

### 🟢 低优先级 — 值得探索但需要更多数据或较大改动

#### 10. 迁移学习 / 多保真度建模

论文数据 (金属玻璃, ~1000K/s 快速升温) 和 PS-DSC 数据 (10K/min 慢速升温) 虽然材料和实验条件不同, 但物理机制 (TNM 玻璃态弛豫) 是通用的。可以用多保真度高斯过程 (Multi-fidelity GP) 将论文数据作为低保真度先验, PS 数据作为高保真度微调。

**前提条件**: 需要更多 PS 实验数据才能评估跨材料迁移的有效性。

#### 11. Batch 贝叶斯优化替代贪心 EIG

当前 EIG 是贪心选择 (一次选一个候选, 加 diversity penalty)。改用 q-Expected Improvement 或确定性互信息最大化 (Determinantal Mutual Information), 可以选出一批真正在预测空间互补的实验, 而非仅靠特征空间距离来近似。

**前提条件**: 需要模型不确定性校准 (改进 #8) 作为前置。

#### 12. 循环实验验证闭环

当前 pipeline 止于生成 `.mtd` 方法文件。最有力的验证是:

1. 执行 EIG 推荐的下一轮实验
2. 将新数据加入训练集
3. 重新训练模型
4. 对比预测误差的变化趋势 (应该收敛)

如果经过 2-3 轮循环后预测误差不降反升, 说明模型假设有问题。这是检验模型预测能力的黄金标准。

#### 13. Pareto 前沿探索

逆向设计的加权求和 `L = Σ w_k · |pred_k - target_k| / scale_k` 将多目标压缩为单目标。对于实际应用场景 (如"焓恢复要大 + 实验时间要短"), 应该返回 Pareto 前沿让实验者根据实际约束选择, 而非一个硬编码权重的 Top-K。

## 优先实施路线图

### 第一阶段 (1-2 天, 预期改善 10-15%)

1. **各向异性核 ARD** → 自动发现重要特征, 改善泛化
2. **交互特征** → 增强路径依赖性编码
3. **S* 插值改进** → 消除查表偏差

### 第二阶段 (3-5 天, 预期累计改善 20-30%)

## 关键风险与注意事项

1. **ARD 在小样本下可能过拟合**: 17 个特征学习 17 个 bandwidth 参数, 需要正则化 (如对 log σₖ 加 L2 先验)
2. **TNM 参数学习可能缺乏唯一性**: 不同的 (H*, A, β) 组合可能给出相似的 dose 曲线。建议固定 A 或 β 中的一个, 学习其余两个
3. **交互特征可能引入多重共线性**: 新增的交互项与原始特征高度相关。但对 RBF 核回归 (基于距离) 来说, 共线性的影响比线性模型小得多
4. **所有改进都应在 grouped split 下验证**: 不能用随机划分, 否则相关样本泄露会给出虚假的好结果
5. **当前 PS 数据量太少 (~50 样本), 不要引入深度学习**: 任何需要 >100 参数的模型都会严重过拟合。坚持非参数/半参数方法

### 审查发现的关键新问题

#### 🔴 问题 A: 测试集极小导致指标不可信

**现状:** `ps_train_test_metrics.json` 显示 `n_train=99, n_test=6`.

在 grouped split (按 source_file + mode + T1 分组) 下，仅 6 个样本落入测试集。这意味着:
- 所有 MAE/RMSE/R² 的置信区间极宽
- 不同模型变体之间的 MAE 差异 (如 0.174 vs 0.126) 在统计上可能不显著
- 此前"物理核相对原始核改进 31%"的结论需要附上误差棒

**具体证据:**

```
raw_kernel:       ΔH_total R² = -0.175  (负值!)
physics_kernel:   ΔH_total R² = 0.118   (仅勉强为正)
physics_residual: ΔH_total R² = 0.118
```

即便最好的模型, 对 ΔH_total 的解释方差也仅 12%。对于 recovery_index, 所有模型的 R² **全部为负**——预测值比直接用训练集均值更差。这是一个非常严重的信号。

**建议:** 改用 leave-one-group-out (LOGO) 或至少保证测试集 ≥20 个样本。当前 99/6 的划分无法支撑任何严肃的模型对比结论。

---

#### 🔴 问题 B: 时间参数完全不可辨识

**现状:** 来自 `ps_inverse_identifiability_four_step_update.md`:

```
T1 MAE:              8.60°C   (可接受)
T2 MAE:             10.26°C   (勉强)
t1 median factor:   49.98x    (完全不可用)
t2 median factor:    5.00x    (非常差)
Top-5 near-match:   15.8%     (很低)
```

t1 的中位倍数误差是 50 倍——意味着模型无法区分 10 秒和 500 秒的退火。这不是"多补点数据"能解决的表面问题, 而是**特征集本身对时间分配不敏感**的深层问题。

**根因分析:** 当前 TNM dose 特征 `D(T, t) = 1 - exp(-(t/τ)^β)` 在 t ≫ τ 时饱和 (dose → 1), 丧失时间分辨率。在 PS 的 Tg 附近 (~373K), τ 很小, 几乎所有 t ≥ 60s 的退火都产生接近 1 的 dose 值。因此不同 t1/t2 组合在特征空间中**坍缩为同一点**。

**建议:** 这是整个项目当前最核心的技术难题。解决方案需要从特征层面入手:
1. 加入**时间敏感特征**: `log(t1)`, `log(t2)`, `t1/(t1+t2)`, `log(t1/t2)` — 这些不会饱和
2. 使用更慢的 reference τ, 使得 dose 在 10-1800s 范围内保持分辨率
3. 考虑放弃对 t1/t2 的精确反推, 改为反推"总弛豫剂量"和"两步不对称度"

---

#### 🔴 问题 C: EIG 在推向数据真空区而非信息富集区

**现状:** `paper_style_comparison/summary.json` 中 Top-10 EIG 候选:

| Rank | T1 | t1 | T2 | t2 | EIG |
|------|----|----|----|----|-----|
| 1 | 100°C | 100s | 50°C | 100s | 1.61 |
| 2 | 100°C | 100s | 50°C | 60s | 1.61 |
| 3 | 100°C | 100s | 50°C | 30s | 1.61 |
| 4 | 100°C | 60s | 50°C | 300s | 1.61 |
| 5 | 100°C | 100s | 50°C | 300s | 1.61 |
| 6 | 100°C | 100s | 50°C | 10s | 1.60 |
| 7 | 100°C | 60s | 50°C | 600s | 1.60 |
| 8 | 100°C | 60s | 50°C | 100s | 1.60 |
| 9 | 100°C | 30s | 50°C | 600s | 1.60 |
| 10 | 100°C | 30s | 50°C | 900s | 1.60 |

**全部是 T1=100°C, T2=50°C 的 down-jump**, 因为这是训练数据中完全没有覆盖的极端区域。模型在此处的预测不确定性极高——但这是**缺乏数据的方差**, 不是**有科学价值的方差**。

与此同时, `evaluate_inverse_by_temperature.py` 明确指出最需要补数据的是 **50-60°C 和 65-75°C 区间**, 但 EIG 完全没有推荐这些区间。

**根因分析:** EIG 公式中的 novelty 项 (`novelty_weight=0.12 × nearest_distance`) 在特征空间的外推边界 (T1=100, T2=50) 产生最大距离, 主导了总分。而真正需要补的 50-75°C 区间由于已有少量数据, novelty 距离较小, 反而排名靠后。

**建议:** 
1. 对 novelty 项在训练数据凸包之外时施加惩罚 (而非奖励)
2. 将 EIG 的候选空间限制在训练数据覆盖的温度区间内 (interpolation regime)
3. 手动添加 50-60°C 和 65-75°C 的网格补点, 不依赖 EIG 自动选择

#### 🟡 问题 D: 存在退化目标 (零方差)

**现状:** `ps_train_test_metrics.json`:

`kovacs_peak_label` 在所有 105 个样本中全部为 0——该目标对训练和预测提供**零信息**, 应从模型目标列表中移除。

`onset_temperature_C` 的标准差仅 0.006°C——本质上是一个常数 (~70°C)。同样提供极少的有效信息。保留它只会稀释多目标损失中有意义目标的权重。

**建议:** 从 `TARGETS` 中移除 `kovacs_peak_label`。将 `onset_temperature_C` 降级为被动记录值, 不作为预测目标。

#### 🟡 问题 E: 双步数据覆盖极度不均

**82% 的双步数据集中在 80-90°C。** 且该区间内只有两种路径: 80→90 和 90→80。模型学到了"80-90°C 区域的平均 DSC 响应", 但完全没有泛化到其他温度区间的能力。

#### 🟡 问题 F: Paper-style S*/H* 代理量完全不可预测

**现状:** `paper_style_comparison/summary.json`:

```
paper_s_star_eff_J_mol_K:  MAE = 193.8,  target_std = 255.3,  R² = -0.025
paper_h_star_eff_kJ_mol:   MAE = 73.3,   target_std = 96.3,   R² = -0.026
```

这两个 ARRT 代理量的 R² **为负**, 意味着从 7 维原始特征完全无法预测它们。这有两个可能原因:

2. 7 维原始特征缺少对 DSC 峰形动力学信息的编码

#### 🟢 问题 G: Fig.3 H*/Tp 特征反而损害了 ΔH 预测

**现状:** `train_test_split_metrics.json`:

```
ΔH baseline (不含 Fig.3):  MAE = 0.0510, R² = 0.786
ΔH enhanced (含 Fig.3):    MAE = 0.0555, R² = 0.734  ← 变差了!
```

加入 Fig.3 的 H*/Tp 特征后, ΔH 的 MAE 上升了 9%, R² 下降了 5 个百分点。只有 S* 和 ΔS* 得到了改善。这说明 Fig.3 数字化数据中的 H*/Tp 存在**系统性偏差**——它们来自 1000K/s 快速升温的金属玻璃实验, 与当前模型的退火条件存在物理上的不一致。

**建议:** 
1. 对 Fig.3 特征做**消融实验**: 逐个移除 H*₁, H*₂, Tp₁, Tp₂, 看哪个在损害 ΔH 预测

### 对原始 13 条建议的修订判断

审查后, 原建议中有 5 条**已经实现** (#1 部分, #5 部分, #8 部分, #9, #12)。但更重要的发现是: **当前模型的核心瓶颈不是模型架构, 而是数据和评估方法**。具体来说:

1. **99/6 的 train/test 划分**使得所有模型对比缺乏统计效力——无法判断哪个模型真的更好
2. **时间参数的不可辨识性**是特征工程的根本性缺陷, 不是调参能解决的
3. **EIG 的方向性偏差**意味着如果按照当前 EIG 推荐去做实验, 钱和时间可能花在错误的地方
4. **双步数据 82% 集中在一个温度区间**, 任何模型都无法在只有 18% 数据的区间做出可靠预测

**一句话总结:** 代码架构和方法论方向是对的, 但当前最需要的不是更多模型技巧, 而是 (a) 修复评估方法 → (b) 解决时间不可辨识 → (c) 系统性补数据覆盖缺失区间。此后再回头做模型优化, 效果才会真正显现。

### TNM 校准模型架构解析

#### 核心设计

```python
# 仅3个可学习参数
@dataclass(frozen=True)
class TnmParameters:
    activation_energy_kj_mol: float  # 活化能 E
    beta: float                      # 拉伸指数 β
    log10_tau_ref_s: float           # 参考弛豫时间 log10(τ_ref)
```

固定参考温度 `T_REF_K = 373.15` (100°C, PS 的 Tg 附近)。

#### 12维 TNM 状态特征

| 特征 | 物理含义 | 取值范围 |
|------|----------|----------|
| `tnm_step1_state` | 第一步弛豫完成度 | [0, 1] |
| `tnm_step2_only_state` | 第二步独立弛豫完成度 | [0, 1] |
| `tnm_total_state` | 两段序列弛豫后的总状态 | [0, 1] |
| `tnm_step2_increment` | 第二步增量 (total - step1) | [0, 1] |
| `tnm_path_excess` | 路径超额 (total - matched_t2) | [-1, 1] |
| `tnm_temperature_path_span` | 温度路径跨度 (matched_t2 - matched_t1) | [-1, 1] |
| `tnm_equivalent_state` | 等效温度单步弛豫 | [0, 1] |
| `tnm_step1_fraction` | 第一步占比 (step1/total) | [0, 1] |
| `tnm_delta_T` | 温差 T₂ - T₁ | [-50, 50] |
| `tnm_log_total_time` | 对数总时间 | [-1, 3.3] |
| `tnm_log_t_ratio` | 对数时间比 log(t₂/t₁) | [-2.3, 2.3] |
| `tnm_delta_T_log_t_ratio` | 温差×对数时间比 (交互项) | — |

#### 线性观测头

Ridge 回归 (λ = 1e-4) 将 12 维 TNM 特征映射到 4 个核心目标:

```
delta_h_total_J_g, peak_area_J_g, recovery_index, path_dependence_index
```

#### 参数选择

在 150 个候选组合 (6 种 E × 5 种 β × 5 种 τ_ref) 上做 5-fold CV, 选最优者。

### 当前效果

**选定参数**: E = 300 kJ/mol, β = 0.75, log₁₀(τ_ref/s) = 2.0 (即 τ_ref = 100s @ 100°C)

**测试集表现** (n_test = 6):

| 目标 | MAE | R² | vs 物理核 MAE | vs 原始核 MAE |
|------|-----|----|--------------|--------------|
| ΔH_total | 0.106 | **0.386** | 0.126 | 0.174 |
| peak_area | 0.086 | **0.468** | 0.076 | 0.125 |
| recovery_index | 0.151 | **0.300** | 0.182 | 0.254 |
| path_dependence | 0.096 | **0.189** | 0.089 | 0.130 |
| **Core normalized** | **0.666** | — | 0.702 | 1.020 |

**关键成就: 首次所有 4 个核心目标的 R² 全部为正！** 之前的物理核和原始核都有负 R²。

### 发现的改进空间

#### 🔴 问题 1: CV 参数选择与测试评估用了不同的划分方式

**代码证据** (`tnm_calibrated_model.py:190-191`):

```python
folds = np.array_split(train_idx, min(5, max(2, len(train_idx) // 8)))
```

`np.array_split` 按位置连续切分, **不尊重分组结构**。这意味着同一个 `(source_file, mode, T1_C)` 组的样本可能同时出现在训练和验证折叠中, 造成**信息泄露**。

对比 `grouped_split()` 使用 `(mode, source_file, T1_C)` 三元组做分组划分, CV 内部的 `np.array_split` 完全绕过了这个保护。

**后果**: CV 分数 (1.52) 与测试分数 (0.67) 之间存在 2.3 倍的巨大差距。CV 在参数选择阶段过于悲观(或测试集恰好容易), 导致:
- 不能确定选出的 E=300 kJ/mol 是否真的最优
- 如果 CV 内部有泄露, 则选出的参数可能不是真正泛化最好的

**修复**: 

```python
# 替换 np.array_split 为分组折叠
def grouped_folds(train_idx, rows, n_folds=5):
    groups = {}
    for i in train_idx:
        row = rows[int(i)]
        groups.setdefault((row["mode"], row["source_file"], row["T1_C"]), []).append(int(i))
    keys = list(groups)
    rng = np.random.default_rng(42)
    rng.shuffle(keys)
    fold_keys = [keys[i::n_folds] for i in range(n_folds)]
    for fold_k in fold_keys:
        val_idx = []
        for k in fold_k:
            val_idx.extend(groups[k])
        train_fold = [i for i in train_idx if i not in set(val_idx)]
        if train_fold and val_idx:
            yield np.array(train_fold), np.array(val_idx)
```

#### 🔴 问题 2: 选出的 "最优" TNM 参数与物理测量冲突

| 参数 | hs-01 Kissinger 测量 | CV 选出 | 差异 |
|------|---------------------|---------|------|
| E (kJ/mol) | 427, 455, 541 | **300** | 低 30-45% |
| β | 金属玻璃 0.43 | **0.75** | 高 74% |
| τ_ref (s) | 金属玻璃 6e-22 (A) | **100** | 完全不同量级 |

Top-25 CV 候选全部在 E = 300 或 360 kJ/mol。PS 专属测量的 427-541 kJ/mol **一个都没进前 25**。

**根因分析**: CV 选择的不是物理上最正确的 TNM 参数, 而是**使特征分辨率最大化的参数**。具体来说:
- 较低的 E (300 vs 427) → τ 对温度不那么敏感 → dose 在 50-100°C 范围内有更好的渐变 → 特征更有区分度
- 较高的 β (0.75 vs 0.43) → KWW 曲线更陡 → 在部分弛豫区 (dose 0.1-0.9) 分辨率更高
- τ_ref = 100s → 在 100°C 附近 dose 范围覆盖 [0.1, 1.0] → 恰好匹配实验时间窗口

**这不一定是个 bug**——对于预测任务来说, 特征分辨率比物理真实性更重要。但需要在文档中明确说明: "选出的 TNM 参数是预测最优的**有效参数**, 不是 PS 材料的本征物理参数"。

**改进建议**:
1. 在模型报告中加入"有效参数 vs 本征参数"的免责声明 (当前 `model_role` 字段已有类似表述)
2. 如果未来需要桥接两者, 可以考虑: 固定 E 为 hs-01 测量值的加权平均 (如 460 kJ/mol), 仅优化 β 和 τ_ref
3. 在 `parameter_grid()` 中加入 hs-01 测量值附近的精细网格, 看是否有局部最优

#### 🟡 问题 3: 线性头的强系数暗示特征共线性

**代码证据** (`ps_calibrated_tnm_model.json` 的 `coef`):

```
tnm_total_state      →  coef = [-9.74, -11.38, 3.34, -10.84]  (对4个目标)
tnm_step2_increment  →  coef = [3.25, 4.01, -0.70, 3.67]
tnm_path_excess      →  coef = [6.40, 7.51, -2.07, 7.30]
```

Ridge λ = 1e-4 几乎为零, 而系数却达到 10+ 的量级。这表明:
1. `tnm_total_state` 和 `tnm_step2_increment` 和 `tnm_path_excess` 之间存在高度共线性
2. 它们三个加起来可以完美重构 `tnm_total_state` (因为 `total = step1 + increment`)
3. 线性头在几乎无正则化的情况下学习到了"大系数互相抵消"的模式

**风险**: 加入少量新数据后, 这些大系数可能剧烈变化, 导致预测不稳定。

**改进建议**:
1. 增大 ridge 到 0.01-0.1, 压制系数幅度
2. 或者从 12 个特征中移除共线冗余: `tnm_step2_increment = tnm_total_state - tnm_step1_state` (完全共线)
3. 在 `select_parameters()` 的 CV 循环中也输出系数的条件数, 作为模型稳定性指标

#### 🟡 问题 4: recovery_index 存在系统性低估

**代码证据** (`ps_calibrated_tnm_condition_error_analysis.md`):

```
recovery_index overall bias: -0.107 (预测值系统性偏低)
```

按 T1 区间分组:
```
50-60°C: bias = -0.041
65-75°C: bias = -0.032
80-90°C: bias = +0.027
95-100°C: bias = +0.059
```

存在**温度相关的系统性偏差**: 低温区低估, 高温区高估。这指向 TNM 模型在低温下的弛豫速率估计偏慢——低温时预测的恢复量不够, 高温时预测过多。

**根因**: E = 300 kJ/mol (偏低) 导致 τ(T) 对温度的敏感性不足。在低温 (50°C) 时, τ 应该更长 (dose 更小), 但低 E 使得 τ 增长不够快, 导致预测 recovery 偏高 (正 bias)。等等, 实际 bias 是负的... 

让我重新计算。在 50°C, E=300: τ(50°C) = 100 × exp(300000/8.314 × (1/323.15 - 1/373.15)) = 100 × exp(36085 × 0.000414) = 100 × exp(14.94) ≈ 3.1×10⁸ s。这确实很长, dose 接近 0。

在 100°C, E=300: τ(100°C) = 100 × exp(0) = 100s。dose(t=1800s) = 1-exp(-(18)^0.75) ≈ 1-exp(-8.7) ≈ 0.9998。

所以 TNM 模型预测 50°C 几乎无恢复, 100°C 几乎完全恢复。但实际数据中 50°C 仍有一些恢复, 100°C 的恢复也达不到理论最大值。这个偏差来自:
- 实际 PS 在低温下仍有一些 sub-Tg 弛豫 (TNM 单一活化能不能捕捉)
- 100°C 的实际恢复受限于 1800s 的时间窗口和仪器灵敏度

**改进建议**:
1. 对 recovery_index 的预测加一个**温度相关的 bias correction 项**
2. 或使用两个活化能的 TNM 变体 (一个用于低温, 一个用于高温)
3. 更简单的做法: 在最终输出上做保序回归校准

#### 🟡 问题 5: path_dependence_index 在极端时间比工况下误差巨大

**代码证据** (worst exact conditions):

| 工况 | path_dep MAE |
|------|-------------|
| T1=80,t1=50, T2=90,t2=0.1 | **0.428** |
| T1=90,t1=500, T2=80,t2=1.0 | **0.370** |
| T1=80,t1=50, T2=90,t2=1000 | **0.352** |
| T1=65,t1=10, T2=85,t2=600 | **0.239** |

这些都是 t₁ 和 t₂ 极端不对称的路径——恰恰是路径依赖效应最强的工况。但 TNM 模型在这里误差最大。

**根因**: TNM 的序列状态更新 `advance_state(step1, T2, t2)` 在 t₂ ≪ τ(T₂) 时, `step2_increment ≈ 0`, 路径效应消失。但实际 DSC 数据显示, 即使第二步极短, 仍有路径效应残留——这可能是 TNM 的 KWW 方程无法捕捉的**非指数弛豫尾迹**。

**改进建议**:
1. 在 `tnm_state_features` 中加入 `tnm_step1_logt1` 和 `tnm_step2_logt2` 等**对数时间特征** (它们不饱和)
2. 在损失函数中对极端时间比样本加权, 强制模型关注这些工况
3. 实验层面: 下一轮实验方案中已包含极端时间比工况 (S1-07: t1=10, t2=60), 很好

### TNM 校准路线 vs 物理核路线的判断

| 维度 | 物理核 (physics kernel) | TNM 校准 |
|------|------------------------|----------|
| 可学习参数 | 0 (非参数) | 3 + 13×4 = 55 (线性头) |
| 特征维度 | 7 raw + 6 physics = 13 | 12 TNM state |
| 物理先验强度 | 弱 (能量网格"撒网") | 强 (TNM 方程结构) |

**结论: TNM 校准路线是正确的方向转变。** 它用 3 个物理参数 + 线性头替代了 100+ 维特征的核回归, 在更少的有效自由度下实现了更好的 R²。但上述 8 个问题需要在下一步迭代中解决。
